FIRST RUN · NOTHING TO CONNECT
想接入真实模型？先了解边界与下一步。
  1. 当前版本只有 Mock：先练习取舍、审阅、模拟任务与下载 JSON，不会生成真实视频。
  2. 真实运行需后续的本地应用或可信服务端，使用 credential provider 从环境变量/密钥库读取凭据；该接口尚未实现。
  3. 分别配置 Agent backend 与生成 provider；验证协议、模型能力、附件支持及各自计费，不假定网页会员覆盖 API。
  4. 密钥不能放入公开 Pages、流程图、日志或导出文件。这里仅演示 credential reference，不接收真实 Key。
