# MV 制作

交付成片、可编辑字幕和一份简短的复核清单。此 skill 是制作流程，不是本站的网页功能，也不提供内置歌唱、听写或渲染程序。

## 1. 先定音轨和歌词

- 用有相应使用权的原唱、录音或 AI 演唱；尚未出歌时，也可以先用审核过的歌词与曲风提示生成候选。只有明确需要按谱重合成时，才转到[旋律与人声工作流](../README.md)。生成、上传、商用和发布不是同一项权限。
- 冻结当前混音、确认版歌词和输出规格。原语言文字、供演唱引擎读音的注音版、译文分别保存。只有录屏时，若用途与许可允许，仅在本地提取授权的音轨；要求只取声音时，不能把录屏截图或原始画面带入 MV。
- 多次演唱共在一个文件时，用声音起伏、歌声/静音、前奏或结尾作候选分界，再复听，特别区分段间静音与歌曲内部停顿。记录原文件时间与裁出后从零开始的时间；即使歌词一样，每个唱法都单独对齐。

## 2. 用粗识别找位置，用已知歌词定内容

1. 在当前音轨分段做语音识别或听辨，记录清楚的音节、押韵、独特短语和段落入口。轻声、假声、拖长元音或伴奏盖住人声时，把识别当线索，不当歌词。
2. 以已知歌词的行序为约束，从清楚的锚点往后对，再从后一处清楚的锚点往前对。给每次副歌独立编号；只有重复文本而没有段落或时间证据时，不要把同一句硬配到另一次演唱。发现可能漏唱、重唱或改词时记为差异，不把原稿自动补进成片。
3. 给每行记录版本、段落、行号、起止、证据及置信程度。边界看实际字头、尾音和停顿；不要把前后整段平均分给每句。两端锚点夹住一句仍不能证明唱过：证据不够就紧邻锚点局部复听或重跑短窗口，仍不确定则留空，并在清单标出。
4. 按需要交烧录双语和可编辑 SRT/ASS，默认可用上行原文、下行译文。注音仅在有需要时另层呈现，不把发音输入稿原样当显示字幕。检查双语成对、区间排序、不重叠、不越界及各次重复是否正确。参考[虚构时间轴验收例](references/alignment-fixture.md)。

## 3. 按真实时间轴做画面

- 用已对齐的段落、歌词转折和音乐重拍做分镜：确定背景、角色/动作、镜位、前景遮挡和切点；重复副歌可复用角色资产，换机位或动作来回应当前段落。留出无歌词的前奏、停顿和尾奏。
- 先锁统一角色设定与输出画布。主角、配角和群众都用同一规格的透明 GIF：每人保留同样的画布、描边基准、透明处理及尺度参考，可预先画统一透明边界内的几种表情和动作。预览在深浅两种底上的边缘、位置、循环接缝和动作方向。别把带字画面或不一致的低清角色混进统一群像。
- 背景独立生成静图，保持同一美术风格与场景视角，提示中明确无人物、无文字，留动作区和字幕安全边距。在合成中用镜头位移、缩放、停顿和前后景层次增加动感；不把整片导成 GIF，也不把换背景等同于完成角色表演。

## 4. 渲染与验收

用最终音轨驱动合成，明确选择音视频流；按目标画幅导出 MP4，保留可编辑字幕和分镜。先试渲染最长双语字幕、群像、强动作和一个副歌切点。全片技术验收要检查完整解码、时长、两端静音/尾奏、所用音轨和分辨率；随机抽帧不能替代这些检查。视觉检查双语字体、可读性、角色层和字幕遮挡；同步检查首句、重复段、停顿后第一句、低置信片段、尾句。分开记技术检查、抽样复看和实际听审，没有完整听过就不写全片听审。换版本可复用图层，不复用旧时间码；字幕改变后复查相应画面事件。私有成片默认只走用户指定的交付渠道，不把真实唱词、录音、截图、工程数据或私链带入公开仓库。

通用封装及换轨细节见[双语试听视频工作流](../BILINGUAL_VIDEO_WORKFLOW.md)。
