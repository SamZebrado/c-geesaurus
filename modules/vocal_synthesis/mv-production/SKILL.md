# MV 制作

先把歌和字幕的时间对上，再沿同一条时间轴排画面。交付 MP4、可编辑字幕和简短的复看记录。

## 1. 选定歌曲和歌词

- 选一版要用的演唱：可以用有使用权的录音，也可以拿定稿歌词和曲风说明做一首新歌。要按谱调整已有的演唱，见[旋律与人声工作流](../README.md)。
- 固定这次的混音、确认版歌词和画幅。原文、给演唱工具读的注音、译文各存一份。素材是录屏且只用声音时，在本地单独提取音轨。发布前按实际用途核对歌、歌词、录音和画面的使用许可。
- 一个录音有多种唱法时，先听前奏、停顿和尾奏，找出每次演唱的分界。记下原录音里的切点和切出后从零开始的时间，各版本单独对字幕。

## 2. 听出几处锚点，再对齐已知歌词

1. 分段听或做粗识别，先记清楚的音节、押韵、特别好认的词，以及副歌开始的位置。遇到假声、拖音、伴奏盖住人声，用这些清楚的片段定位。
2. 拿确认版歌词，从一处锚点向后找，再从下一处锚点往前核。每次副歌都按它在录音里出现的位置单独编号。发现漏唱、重复或改词，把实际唱法和歌词稿的差异记下来。
3. 逐句记段落、行号、开始、结束和听辨依据，跟着字头和尾音卡时间。夹在两个锚点之间还听不清的句子，缩短窗口复听或再识别一次；仍对不上就让字幕留空，记下位置待复听。
4. 双语可用原文在上、译文在下。交付可编辑 SRT/ASS，需要固定样式时再烧录到画面。检查两行是否成对、时间是否顺序正确、有无重叠或超出歌曲长度。用[虚构时间轴验收例](references/alignment-fixture.md)试一次重复副歌和过门。

## 3. 把画面排在同一条时间轴上

- 用歌词转折、音乐重拍和段落切点排背景、动作、机位。前奏、过门和尾奏也各留一段画面。
- 主角、配角和群众都用透明 GIF。先定统一的画布、描边和人物比例，再做几种表情、站位和动作。分别在深色、浅色背景上看边缘和循环接缝。
- 背景另做静图，统一场景画风和视角，留出角色活动区、字幕区。需要动感时，可换机位、轻推镜头，或让不同层以不同速度移动。重复副歌可以沿用角色 GIF，另排动作。

## 4. 导出前复看

用最终混音和目标画幅导出 MP4，保留字幕和分镜。先试导最长的双语行、群像和一个副歌切点，再检查全片能解码、启用的音轨正确、字幕清楚、结尾留全。重点复听首句、两次副歌、停顿后第一句、拿不准的句子和最后一句。复看记录分开写文件检查、抽帧和实际听过的范围。

换一版演唱时可沿用角色与背景，重新对这一版的歌词时间和切点。真实素材留在指定的交付位置，公开教程用另写的虚构例。

封装与换音轨见[双语试听视频工作流](../BILINGUAL_VIDEO_WORKFLOW.md)。
